# Superpowers

Use the superpowers plugin for all work, however small. Before any response or action, check its skills and invoke every one that applies: `brainstorming` before building or changing behaviour, `writing-plans` and `executing-plans` for multi-step work, `systematic-debugging` for bugs, `test-driven-development` when writing code, `verification-before-completion` before saying something is done or raising a PR. Repo rules and my instructions still win where they conflict.

If the plugin isn't installed, say so in one line and run `claude plugin install superpowers@claude-plugins-official`.
